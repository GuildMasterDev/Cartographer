# Cartographer

An interactive mapping application built with Electron and OpenStreetMap. Explore the world without requiring location permissions.

## Features

- 🗺️ Interactive OpenStreetMap integration using Leaflet
- 📍 Quick navigation to major world cities
- 🎨 Multiple map styles (OpenStreetMap, Topographic, Dark Mode, Watercolor)
- 📌 Click-to-add custom markers with coordinates
- 🛤️ Route drawing demonstration
- 📊 Real-time coordinate tracking
- 🔒 Privacy-focused - no location permissions required

## Prerequisites

- Node.js (v14 or higher)
- npm

## Installation

```bash
# Clone the repository
git clone https://github.com/guildmasterdev/Cartographer.git
cd Cartographer

# Install dependencies
npm install
```

## Usage

```bash
# Start the application
npm start
```

## Controls

- **City Navigation**: Quick jump buttons to New York, London, Tokyo, and Paris
- **Map Styles**: Choose between different map rendering styles
- **Add Marker**: Click the button or click anywhere on the map to place markers
- **Clear Markers**: Remove all custom markers from the map
- **Draw Route**: Display a sample route with waypoints

## Technology Stack

- **Electron**: Cross-platform desktop application framework
- **Leaflet**: Open-source JavaScript library for interactive maps
- **OpenStreetMap**: Free, editable map of the world
